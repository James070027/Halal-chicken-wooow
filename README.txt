HALAL CHICKEN KITORO HQ - WEBSITE
=================================
Open index.html to view the site. Upload ALL files and folders together to your host (keep the same folder layout).

FILES
index.html            page structure
style.css             colours and layout
config.js             THE FILE TO EDIT: phone numbers, licence numbers, social links, prices,
                      opening hours, delivery fees, bulk-bonus tiers, reviews, video/photo names
i18n.js               English / Kiswahili / Luganda text (have a native speaker check Luganda)
app.js                the site's logic (normally not edited)
sw.js, manifest.webmanifest, icons/   make the site installable as an app (needs https)
images/               put your real photos here (names are listed in images/README.txt)
videos/               put farm video here as farm.mp4

BEFORE LAUNCH, the owner must confirm: prices, delivery fees, bonus percentages, About-page story,
reviews and rating (keep only real ones), and add licence numbers in config.js when received.
